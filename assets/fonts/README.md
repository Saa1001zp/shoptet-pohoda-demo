# Fonts

Tieto fonty sa používajú len na generovanie screenshotov a videa v tomto deme.
Sú to open-source fonty z projektu Google Fonts, licencia SIL Open Font
License 1.1 (OFL-1.1).

| Súbor | Rodina | Zdroj |
|---|---|---|
| `Newsreader.ttf` | Newsreader | https://github.com/google/fonts/tree/main/ofl/newsreader |
| `Inter.ttf` | Inter | https://github.com/google/fonts/tree/main/ofl/inter |
| `JetBrainsMono.ttf` | JetBrains Mono | https://github.com/google/fonts/tree/main/ofl/jetbrainsmono |

Fonty nie sú súčasťou webu perepolkin.sk; web používa svoje vlastné fonty.
